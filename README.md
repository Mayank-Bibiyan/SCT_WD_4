# 📝 To-Do Web Application

A responsive and user-friendly To-Do Web Application built using HTML, CSS, and JavaScript. This application helps users efficiently organize, manage, and track their daily tasks with advanced task management features.

## 🚀 Features

* ➕ Add new tasks with a custom task name
* 📅 Set task date and time
* 🔥 Assign priority levels (High, Medium, Low)
* 🔍 Search tasks instantly
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 📋 View pending tasks separately
* 🎉 View completed tasks separately
* 📱 Responsive design for various screen sizes
* 🎨 Clean and intuitive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
